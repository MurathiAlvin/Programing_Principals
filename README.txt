M-Nest Bank C++ School Project
==============================
Files:
- m_nest_bank.cpp: complete C++17 source code
- M_Nest_Bank_Documentation.docx: project documentation
- flowchart.mmd: complete Mermaid flowchart

Compile:
g++ -std=c++17 -Wall -Wextra -pedantic m_nest_bank.cpp -o m_nest_bank

Run:
./m_nest_bank

Data files are created in the directory from which the executable is run:
- accounts.txt
- transactions.txt
